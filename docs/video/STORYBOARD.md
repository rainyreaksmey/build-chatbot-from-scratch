# Nova chatbot video storyboard

Duration: 30 seconds. Format: 1920×1080 at 30 fps.

| Time | Visual | Narration |
| --- | --- | --- |
| 0–5s | Title and glowing Nova mark | “Let’s build a chatbot you can train and understand.” |
| 5–11s | Training phrases flow into token cards | “Examples are split into words and grouped by user intent.” |
| 11–18s | Animated probability bars | “A small Naive Bayes model scores each possible intent.” |
| 18–25s | Chat window demonstrates a question and answer | “FastAPI connects the model to a polished browser chat.” |
| 25–30s | Four-step command sequence | “Edit the examples, retrain, test, and keep improving.” |

The companion Remotion composition is stored in the main repository video
project as `ChatbotIntro`. Render instructions are in this folder's README.
